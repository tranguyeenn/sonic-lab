## Genres

- [ ] Minimal techno — single element evolving over 8+ minutes, almost nothing else
- [ ] Lo-fi hip-hop beat — dusty drums, vinyl crackle sample, jazzy chord voicings
- [ ] Dark ambient — no kick, only texture and slow harmonic drift
- [ ] UK garage — shuffled 2-step rhythm at ~130 BPM
- [ ] Synthwave — arpeggiated `:prophet` lead, `:dsaw` bass, 80s tempo (~110 BPM)
- [ ] Drill — sliding 808-style bass using `:fm` with pitch bends

---

## Experiments

- [ ] Euclidean rhythms — implement basic Euclidean pattern generator in Ruby
- [ ] Markov chain melody — notes that depend on the previous note's probability
- [ ] Live parameter morphing — use `sync` and variables to shift BPM or key mid-piece
- [ ] Silence as element — intentional gaps in rhythm, measure the effect
- [ ] One synth only — entire track using a single `:prophet` patch
- [ ] Random vs. structured — A/B test generative `.choose` vs. fixed `tick` patterns


---

## Generative Music

- [ ] Evolving chord progression — progression that shifts after N bars via `tick` offset
- [ ] Self-varying density — `one_in(n)` where `n` changes over time
- [ ] Scale rotation — melody in C major for 16 bars, then A minor, then back
- [ ] Generative bass — root note follows progression, octave and rhythm randomized
- [ ] Seed-based reproducibility — use a fixed random seed to recreate a "random" piece
